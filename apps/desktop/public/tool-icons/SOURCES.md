# Additional Agent icons

The added Kimi Code, DeepSeek Harness, Antigravity CLI, Zed, Command Code,
WorkBuddy, Cline, TRAE and Qoder tool SVGs reuse the matching bundled provider
assets from `packages/ui/src/assets/provider-icons` (Kimi uses Moonshot).
See that directory's `SOURCES.md` and `LICENSE-LOBE-ICONS` for provenance and
license notices. Trademark rights remain with their respective brands.
Tools without a verified mark use the normal Terminal icon.
